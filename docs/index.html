Built to come back

Spotify updated? Already fixed.

Spotify updates itself and wipes every customization. Snowtify's guard notices within seconds and puts your setup back — before you even open a playlist.

  1. Spotify updates itselfIts new files replace your theme and extensions.
  2. The guard noticesA tiny check every few seconds spots the change.
  3. Everything comes backSnowtify reapplies your exact setup and restarts Spotify.

Updates without commands

New version? It installs itself.

When a new Snowtify ships, you'll see it right inside Spotify. It downloads, reapplies your setup and restarts Spotify — no PowerShell, no copy and paste.

  • Keeps your setup. Themes, extensions, custom apps and settings stay as they are.
  • Follows Spicetify closely. New Spicetify releases are merged and shipped within hours.
  • Safe by design. Only Spotify itself can ask the guard to update; websites can't.

Questions

Good to know

I already use Spicetify. Will I lose anything?

No. Snowtify uses the same configuration folder, so your themes, extensions and Marketplace stay exactly as they are.

What happens when Spotify updates?

The guard reapplies Snowtify automatically, usually within a minute. If that Spotify version isn't supported yet, it restores stock Spotify so it keeps working and retries when a Snowtify update is out.

Does the guard slow my PC down?

No. It reads one folder every few seconds and otherwise sleeps. It only does real work right after Spotify updates.

Is it safe?

Snowtify only touches Spotify's own interface files and keeps a clean backup. The guard listens only on your own computer and only accepts requests from Spotify.

How do I remove it?

Run the uninstaller from the docs. It restores Spotify first, then removes Snowtify; your other Spicetify settings are left alone.
