Snowtify guide · v2.46.7-snow.2

Documentation

Install once. Snowtify keeps your themes and extensions working through every Spotify update.

01

Installation

Windows 10 or 11 with the desktop version of Spotify.

Before you start: use Spotify from spotify.com, not the Microsoft Store version, and open PowerShell as your normal user (not as administrator).

PowerShell
iwr -useb https://raw.githubusercontent.com/SnoW-099/snowtify/main/install.ps1 | iex

The installer downloads Snowtify, optionally installs Marketplace, applies Snowtify to Spotify with your current theme and extensions, and turns on the background guard.

02

Already using Spicetify?

Nothing to migrate.

Snowtify reads the same %APPDATA%\spicetify folder, so your themes, extensions, custom apps and settings carry over. The spicetify command keeps working as an alias.

03

The guard

A tiny background helper that keeps Snowtify applied.

Spotify updates itself every few weeks and wipes every customization when it does. The guard starts with Windows, checks Spotify's files every few seconds and:

WhenWhat the guard does
Spotify updatedReapplies Snowtify with your setup and restarts Spotify, usually within a minute.
Applying failsRestores stock Spotify so it keeps working, then retries when a newer Snowtify is out.
Snowtify update outInstalls it from inside Spotify with a progress screen, or silently while Spotify is closed.
snowtify guard status

Turn it on with snowtify guard install and off with snowtify guard uninstall. Running snowtify restore pauses auto-repair until you run snowtify apply again. The guard only listens on your own computer and only accepts requests from Spotify.

04

Updates

Automatic with the guard; one command without it.

With the guard on, new versions appear inside Spotify when you open it: Snowtify downloads the release, reapplies your setup and restarts Spotify on its own. Without the guard, Spotify shows an update panel with the command to run:

snowtify update
05

Diagnostics & repair

For the rare case something still looks off.

CommandWhat it does
snowtify doctorChecks Spotify, the backup, theme, extensions and apps without changing anything.
snowtify repairRebuilds the backup if needed and reapplies your setup.
snowtify logsShows the latest diagnostic, repair and guard log.
06

Marketplace & themes

The whole Spicetify ecosystem works.

Snowtify keeps the internal Spicetify API, so Marketplace and community themes, extensions and apps work unchanged. Snowtify never changes your theme. The Snowtify Frost theme is available in Marketplace if you want it.

07

Commands

Everyday reference.

CommandWhat it does
snowtify applyApplies your current configuration to Spotify.
snowtify restoreReturns Spotify to its original state.
snowtify updateUpdates Snowtify and reapplies your setup.
snowtify guard installStarts the guard now and at every logon.
snowtify guard statusShows whether the guard runs and if an update is pending.
snowtify doctorRead-only health check.
snowtify repairReapplies after a problem.
snowtify configShows or changes configuration values.
snowtify -vPrints the installed version.
08

Troubleshooting

Quick fixes.

Snowtify disappeared after Spotify updated

With the guard on, wait a minute: it reapplies on its own. Otherwise run snowtify guard status; if it isn't running, run snowtify repair and then snowtify guard install.

Spotify opens blank or frozen

Disable the last theme or extension you installed, then run snowtify repair. snowtify doctor lists anything missing.

Spotify is back to normal and stays that way

That brand-new Spotify version isn't supported yet, so the guard kept Spotify working. It reapplies automatically once a Snowtify update ships; snowtify logs shows the details.

PowerShell can't find the snowtify command

Close and reopen PowerShell so it reloads your PATH, then run snowtify -v.

09

Uninstall

Restores Spotify first, then removes Snowtify.

Only run this to remove Snowtify. It stops the guard, restores Spotify and deletes the Snowtify program. Your other Spicetify themes and settings are left untouched.

PowerShell
iwr -useb https://raw.githubusercontent.com/SnoW-099/snowtify/main/uninstall.ps1 | iex
